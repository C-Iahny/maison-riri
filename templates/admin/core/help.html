Tout ce que vous modifiez ici est visible sur le site immédiatement, sans rien installer ni redéployer. Une erreur n'est jamais grave : chaque champ peut être corrigé ou vidé, et le site retombe alors sur son contenu d'origine.

Changer une image du site

  1. Ouvrez Images du site et cliquez sur l'emplacement voulu (logo, grande image de l'accueil, portrait…).
  2. Dans le champ Image, choisissez le nouveau fichier sur votre ordinateur.
  3. Cliquez sur Enregistrer. C'est tout.

Formats conseillés : logo carré (600 × 600 px), grande image de l'accueil en paysage (2000 × 1300 px), portrait en 4/5 (1200 × 1500 px). Les fichiers JPEG ou PNG conviennent ; évitez les images de plus de 5 Mo.

Modifier un texte

  1. Ouvrez Textes du site. Le filtre à droite permet de n'afficher qu'une page (Accueil, À propos…).
  2. Cliquez sur le texte à changer : le texte d'origine est rappelé en haut.
  3. Écrivez votre version dans Texte (FR), et si vous le souhaitez la version allemande dans Texte (DE). Laissez le champ allemand vide pour afficher le texte français sur le site allemand.
  4. Enregistrez. Pour revenir au texte d'origine, videz simplement les deux champs.

Pour un texte à plusieurs paragraphes, laissez une ligne vide entre chaque paragraphe. Pour une liste, écrivez un élément par ligne.

Ajouter ou modifier un projet du portfolio

  1. Ouvrez Portfolio puis Ajouter, ou cliquez sur un projet existant.
  2. Choisissez le type : Réalisation pour un événement réalisé, Concept créatif pour un projet imaginé mais non réalisé (l'étiquette s'affiche automatiquement sur le site).
  3. Envoyez l'image de couverture, puis remplissez les textes en français : titre, sous-titre, type d'événement, résumé, texte long. Les textes allemands sont facultatifs.
  4. Plus bas, ajoutez les photos de la galerie en indiquant leur étape (moodboard, détails, installation, résultat final) et les couleurs de la palette.
  5. Cochez Mis en avant sur l'accueil pour que le projet apparaisse sur la page d'accueil, puis enregistrez.

Traiter une demande de devis

  1. Ouvrez Demandes de devis. Les nouvelles demandes sont signalées par une pastille dans le menu.
  2. Cliquez sur une demande pour lire le message, les coordonnées et voir les photos d'inspiration.
  3. Changez le statut au fil du suivi : nouvelle, en cours, devis envoyé, confirmée, classée.

Chaque demande est aussi recopiée dans votre Google Form et envoyée par e-mail à l'adresse de contact du site.

Changer votre mot de passe

Cliquez sur votre nom en haut à droite, puis sur Changer de mot de passe.

Voir le résultat

Le lien Voir le site du menu ouvre le site public. Le site existe en français et en allemand : le bouton de langue en haut de chaque page permet de vérifier les deux versions.
